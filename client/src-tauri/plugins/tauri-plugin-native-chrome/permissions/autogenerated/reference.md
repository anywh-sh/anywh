## Default Permission

Default permissions for the plugin

#### This default permission set includes the following:

- `allow-show-context-menu`
- `allow-set-top-bar`
- `allow-set-top-bar-menu`
- `allow-set-drawer`
- `allow-set-gesture-hint`
- `allow-set-context-target`
- `allow-set-composer`
- `allow-set-composer-text`
- `allow-focus-composer`
- `allow-blur-composer`
- `allow-set-composer-elapsed`
- `allow-set-scroll-to-end`
- `allow-read-attachment`
- `allow-register-listener`
- `allow-remove-listener`
